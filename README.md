# Overview

This repository contains implementations of various frameworks and architectures, such as MLPs, RNNs, CNNs, and transformers, applied to specific text-analytics tasks like Sentiment Classification and POS-Tagging.

Each folder in this repository includes Jupyter Notebooks with code and explanations for different models and tasks.

## Structure

The structure of the repository is as follows:

folder/ 
├── notebooks/ 
└── docs/

- **`notebooks/`**: Contains Jupyter Notebooks with code and implementation details.
- **`docs/`**: Contains documentation and explanation files.
